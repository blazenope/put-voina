# Путь Воина — заметки для Claude

Личное офлайн-приложение Александра (ежедневник + RPG + питомец + трекер без срыва). Один файл `index.html`, сервис-воркер `sw.js`, сайт: https://blazenope.github.io/put-voina/ (GitHub Pages из `main`).

Данные хранятся только в localStorage телефона. Менять их удалённо можно только через `remote.json`.

## remote.json — начисление баллов и правки данных
Приложение при каждом запуске читает `remote.json` и применяет каждое обновление ОДИН раз (по `id`). Старые обновления не удалять — просто добавлять новые в массив `updates`.

```json
{"updates":[
  {"id":"уникальный-id",
   "date":"YYYY-MM-DD",                     // день, в который записать дела (по умолчанию сегодня)
   "grants":[{"t":"Тренировка в зале","xp":30,"c":"str","time":"18:00"}],
   "days":{"YYYY-MM-DD":"c"},               // c = чистый день, f = срыв
   "cleanSince":"2026-11-13T08:00:00+01:00", // начало отсчёта без срыва
   "note":"короткая запись в летопись"}
]}
```
- `c` — характеристика: `str` сила (спорт), `int` разум (учёба, немецкий, заявки, документы, монтаж), `cha` харизма (общение), `wil` воля (быт, дисциплина). Если не указать — определится по словам.
- XP за дело: мелочь 10–15, обычное 20–30, трудное/важное 40–60, подвиг 80–150 (максимум 200). Золото = половина XP, урон по боссу = XP.
- Когда Александр пишет в чат что угодно сделанное (одно дело или список) — САМ оцени важность и сложность, назначь XP по шкале выше с учётом его ситуации (переезд в Мюнхен и Jobcenter, немецкий B1→B2, поиск EQ/Ausbildung, режим сна, спорт, путь без срыва), добавь одно обновление с `grants` и запушь в `main`. Не переспрашивай. Ответ ему: коротко, что начислено.
- **Квесты (план) добавляю я, Александр вручную их не пишет.** Поле `"tasks":[{"t":"Немецкий 30 минут","xp":25,"c":"int","time":"10:00"}]` с `"date"` добавляет НЕвыполненные квесты в план дня (дубли по названию пропускаются, сортировка по времени). Когда он пишет планы/дела на день или неделю — сам разбей на конкретные квесты, оцени XP по шкале выше, одно обновление на каждый день, запушь. Выполненное — через `grants` (если квест уже в плане с тем же `t`, он отметится выполненным).
- Подвиги (80–150): отправил важное письмо/заявление в Jobcenter, подписал договор, прошёл собеседование, тренировка + немецкий + все привычки за день.

## Линия Сердца
Квестовая линия к живой близости (этапы: подготовка, профиль, выход в мир, свидания, близость). Если Александр пишет о шагах по ней (подстригся, поставил Hinge, сходил на свидание, получил номер, отказ) — начисляй через `grants` с `"c":"cha"`; отказы/игнор тоже награждай (~15 XP), это часть механики.
Шаги Линии Сердца отмечай полем `"love":{"id":кол-во}` (id: hair, clothes, groom, gym, smile, photo, app, bio, upload, likes, event, talk, contact, first, ask, date, follow, room, prep, invite, intim; `rej` — отказы). Опыт начисляется автоматически по таблице квеста. Всегда в духе согласия и уважения.

## Игровая механика (кратко)
- Боссы: у каждого слабость (характеристика бьёт ×2) и способность (реген HP за дни без квестов, у «Тени Соблазна» срыв лечит сильнее, у «Голема» обычный урон −20%).
- Экономика: золото = XP/2 × бонусы; серия активности (дни подряд с квестом) +5%/день до +50%; Оружейная 80/250/700/1800 (уровни 1/3/6/10); свитки ×2 на 24 ч.
- Здоровье: у Александра в анамнезе судорожный приступ и эпилептиформная активность на ЭЭГ при гипервентиляции — никогда не советовать быстрое/глубокое дыхание, Wim Hof, ночи без сна. Дыхание только медленное (вдох 4, выдох 6).
