Как играть
  1. Утром впиши задачи дня. Время в начале строки («12:00 врач») расставит их по порядку. Наперёд можно планировать через полосу недели.
  2. Когда тянет, жми «Тянет». Дыши в ритм круга и делай действия по одному. Бой длится 5 минут, «Тяга прошла» доступна через 2. Если тянет дальше, начни ещё один бой.
  3. Вечером отметь итог дня.

Срыв не отнимает уровень и опыт. Заново начинается только таймер. Честная отметка срыва даёт +5 XP.

Опыт: задача из плана +25, привычка +10–25, победа над тягой +50 и +5 за каждое действие, чистый день +20 и бонус за серию, все задачи дня +50, награда +30.

Бесплатная блокировка
  • Android: Настройки → Частный DNS → family.cloudflare-dns.com
  • iPhone: Экранное время → Контент и конфиденциальность → ограничить сайты для взрослых. Код пусть поставит кто-то другой.
  • ПК: расширение LeechBlock NG и DNS 1.1.1.3
